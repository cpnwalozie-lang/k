# Future Chris

A personal growth app: quests with XP, a Future Me coach that checks in like a friend, notes and a journal.

- **Open it:** the GitHub Pages address for this repository (Settings, then Pages, shows it).
- **Your data stays on your phone.** Everything you type is saved in your phone's browser. Nothing is sent anywhere, and nothing you type ends up in this repository.
- **Back up** from the Trophies page now and then.

## Files
- `index.html`: the whole app.
- `manifest.webmanifest` and the `icon-*.png` files: the home screen name and icon.
- `sw.js`: lets the app open without signal.
